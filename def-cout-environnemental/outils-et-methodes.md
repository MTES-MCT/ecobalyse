# Outils et méthodes

Ecobalyse utilise les outils suivants :&#x20;

* Calcul des impacts et construction des inventaires Ecobalyse\_custom\_lci : [Brightway](https://www.google.com/url?sa=t\&source=web\&rct=j\&opi=89978449\&url=https://brightway.dev/\&ved=2ahUKEwi9z9vhj5SYAxVSgP0HHTaWPH4QFnoECCgQAQ\&usg=AOvVaw1Plwsk35dLTynmW226-IMQ)
  * Un calcul avec un second logiciel est réalisé pour vérifier la cohérence des résultats
  * Les inventaires Ecobalyse\_custom\_lci sont décrits dans le dépot Ecobalyse
* Récupération des bases de données : [SimaPro](https://www.google.com/url?sa=t\&source=web\&rct=j\&opi=89978449\&url=https://simapro.com/\&ved=2ahUKEwiB_9-GkJSYAxXKh_0HHaU_OtMQFnoECB8QAQ\&usg=AOvVaw1Ul6kPh7Fdwm-LrUP-QhPw) (csv)
  * Permet historiquement de garantir une uniformité des bases de données
  * En cours de migration pour une importation directe des bases de données (exemple : ecospold pour BAFU:2026)
* Travaux de recherche, analyses, comparaisons, transferts d'arrière-plan : [Volca](https://www.volca.run/)

Méthode de caractérisation : EF3.1 (adapted) 1.03 (SimaPro)
