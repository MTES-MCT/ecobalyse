# ⚠️ Changement de base de données source

{% hint style="info" %}
Les informations suivantes ne s'appliquent pas au textile réglementaire et aux ingrédients alimentaires
{% endhint %}

Nous sommes en train de migrer la base de données d'arrière-plan principale d'Ecobalyse de Ecoinvent vers BAFU  en deux étapes : transfert vers BAFU:2025v2, puis transfert vers BAFU:2026v2 dans les jours suivants sa parution.

{% hint style="warning" %}
**Les impacts vont donc évoluer entre début novembre et mi-décembre.**
{% endhint %}

{% hint style="warning" %}
Les exemples cités dans la documentation ne sont pas à jour, il seront actualisés une fois le transfert vers BAFU:2026v2 finalisé.
{% endhint %}
